cURL to Code

Convert cURL commands to JavaScript Fetch, Python Requests or Node.js Fetch code. Parses methods, headers, query strings, bodies and Basic Auth locally without sending requests.

About this tool

Paste a cURL command copied from browser developer tools, API documentation or a terminal to generate JavaScript Fetch, Python Requests or Node.js Fetch code. Bash/POSIX quoting, line continuations, headers, cookies, text bodies, JSON bodies and Basic Auth are supported.

The converter only parses the command and generates code. It never runs the command or sends a network request. Variables, command chaining and file uploads that cannot be converted safely are rejected instead of producing code with different behavior.

Best use cases

  • Turn a browser “Copy as cURL” request into frontend debugging code.
  • Rewrite cURL examples from API documentation as Python scripts.
  • Reproduce an HTTP request quickly in Node.js.

How to use it

  1. Paste a complete cURL command or load the example.
  2. Choose JavaScript Fetch, Python Requests or Node.js Fetch.
  3. Select Convert, review the generated code, then copy or download it.

Scope and limits

  • Up to 200,000 characters. Only http/https URLs and common request, header, data, cookie, authentication and redirect options are supported.
  • File reads (such as -d @file or -F uploads), shell variables, command substitution, pipes and proxy options are not supported.
  • Browser Fetch is subject to CORS and restricted headers. Do not share generated code containing tokens, cookies or other credentials.

Data processing

The command is parsed in a local browser worker. It is never executed, sent, uploaded or stored.
