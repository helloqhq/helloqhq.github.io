HTML to Markdown

Convert HTML source or UTF-8 files to Markdown with headings, lists, links, quotes, code blocks and simple tables. Highlight, copy and download locally without scripts or resource loading.

About this tool

Paste HTML or import a UTF-8 HTML file to turn articles and rich-text fragments into Markdown. Inspect highlighted input and output, then copy or download an .md file.

Best use cases

  • Turn HTML articles or rich-text exports into Markdown documents.
  • Extract headings, lists, quotes, code blocks and simple tables for a knowledge base.

How to use it

  1. Paste HTML or import a UTF-8 file. Limits: 200,000 characters, 10,000 nodes, 80 nesting levels and 1 MiB per file.
  2. Convert to Markdown, then inspect the read-only output and any conversion notices.
  3. Copy or download an .md file. Editing input clears old output.

FAQ

Is the original page styling retained?

Supported content structure is retained, without CSS layout, styling or script interactions. Merged, irregular and nested tables become readable text with a notice.

Does conversion execute HTML or fetch images?

No. Source is processed in an inert document without insertion into the live page, script execution or external resource loading. Images become reference text only.

How are tables without headings converted?

An empty Markdown header is added and every original data row is preserved. The first data row is not promoted to a heading. Output is limited to 2,000,000 characters.
