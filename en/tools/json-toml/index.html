JSON & TOML Converter

Convert JSON to TOML and TOML to JSON locally with nested objects, arrays, tables, arrays of tables, comments and date/time support. Validate, copy and download without uploads.

About this tool

Convert JSON to TOML and TOML to JSON in one workspace. JSON objects become TOML keys, tables and arrays of tables for configuration preparation, sample migration and API data inspection.

The TOML parser supports comments, dotted and quoted keys, inline tables and standard date/time values. Dates become ISO strings. Because TOML has no null, null values are reported instead of silently dropped.

Best use cases

  • Turn JSON configuration samples into TOML and inspect keys, nesting and arrays of tables.
  • Convert existing TOML configuration to JSON for API debugging, fixtures or documentation.
  • Draft a target configuration format during migration, then review types and edge values.

How to use it

  1. Paste JSON on the left or TOML on the right, or load the examples.
  2. Choose JSON → TOML or TOML → JSON to update the other editor.
  3. Review tables, arrays and date/time values, then copy or download the result.

Scope and limits

  • The top-level JSON value must be an object because a TOML document has a root table.
  • Up to 200,000 characters, 40 nesting levels and 20,000 nodes per conversion.
  • TOML has no null. Integers outside JSON's safe range are reported so they can be represented as strings.

Data processing

Parsing, conversion, copying and downloading run entirely in your browser. Input is never uploaded, stored or executed.

FAQ

Can a JSON array be the TOML root?

No. A TOML document starts with a table, so the top-level JSON value must be an object. Arrays inside objects are supported, and arrays of objects become arrays of tables.

What happens to JSON null?

TOML has no null type. Conversion stops with a clear error so you can remove the field or use an explicit string instead of silently losing data.

Is my configuration uploaded?

No. TOML parsing and JSON conversion run entirely in the current browser without backend requests.
