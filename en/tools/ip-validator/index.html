IP Address Validator

Validate single or batch IPv4 and IPv6 addresses locally in your browser. See address types, error details, counts, and copy results without uploading input.

About this tool

Paste one IP address or a mixed IPv4 and IPv6 list, one address per line, to check format, address type, and error details. Validation runs locally without uploading input.

IPv4 requires four decimal octets from 0 to 255 without leading zeros. IPv6 accepts full notation, one :: compression, uppercase or lowercase hexadecimal, and embedded IPv4 tails. Valid format does not imply allocation or connectivity.

Best use cases

  • Check IP address syntax in configuration files, logs, or documentation.
  • Review mixed IPv4 and IPv6 lists with original line numbers and error explanations.

How to use it

  1. Enter bare IP addresses, one per line. Blank lines and surrounding whitespace are ignored; duplicates are retained.
  2. Select Validate to see totals, valid and invalid counts, and results for each line.
  3. Copy the results or edit the input and validate again.

FAQ

Are CIDR prefixes, ports, and zone identifiers supported?

Only bare IP addresses are accepted. Inputs such as 192.168.1.1/24, 192.168.1.1:80, [::1], fe80::1%eth0, and URLs receive a prompt to remove the extra components.

Are private, loopback, and special-purpose addresses valid?

Yes, when their format is correct. This tool does not check public routing, allocation, or network connectivity.

Must IPv6 use the shortest lowercase notation?

No. Uppercase, leading zeros, and uncompressed forms can be valid. At most one :: is allowed and must replace at least one zero group. An embedded IPv4 tail counts as two groups.
