Shell Editor

Edit Shell, Bash, sh, and zsh scripts locally with syntax highlighting, line numbers, find and replace, undo, file import, and download. No uploads or execution.

About this tool

Create, paste, or import a Shell script in your browser, edit with syntax highlighting, line numbers, and find and replace, then copy or download the result.

Supports .sh, .bash, and .zsh files with four-space indentation. Editing happens locally; scripts are never uploaded or executed.

Best use cases

  • Make quick changes to Bash, sh, or zsh scripts without opening a local IDE.
  • Edit deployment scripts, operations commands, or documentation examples with find and replace.
  • Import an existing script, make changes, and download a UTF-8 file for your own environment.

How to use it

  1. Create a Shell file, paste a script, or import a local .sh, .bash, or .zsh file.
  2. Edit with Tab indentation, Ctrl/Cmd + F for find and replace, and Ctrl/Cmd + Z to undo.
  3. Rename, copy, or download the script. Allow preference storage to restore drafts in this browser.

FAQ

Are my Shell scripts uploaded or executed?

No. Editing, importing, and downloading happen locally without backend execution requests.

Which script files are supported?

Import and download .sh, .bash, and .zsh files. The editor provides Shell syntax highlighting without checking runtime compatibility across shells.

Can I save a draft?

Allow preference storage to save the script and filename in this browser. Shell and PHP editors keep separate drafts.
