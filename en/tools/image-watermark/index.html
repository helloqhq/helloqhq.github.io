Image Watermark

Add text or logo watermarks to static PNG, JPEG and WebP images locally. Adjust text tiling, position, size, color, opacity and rotation. Export at original dimensions.

About this tool

Choose a static PNG, JPEG or WebP image and add text or a local logo. Preview size, position, opacity and rotation in real time, optionally tile text, and download at original pixel dimensions.

Best use cases

  • Add a source or brand to screenshots, portfolio pieces and product photos.
  • Place a single label or tiled text before sharing images.

How to use it

  1. Choose a base image, then enter text or select a local logo.
  2. Adjust size, opacity, rotation and position. Text watermarks also support color and tiling.
  3. Choose PNG, JPEG or WebP, review the preview and download the image.

FAQ

Will exporting shrink the image?

The preview scales to the screen, while exports retain original pixel dimensions. Each image allows up to 20 MiB, 24 megapixels and 8,192 pixels per side.

Are transparent and animated images supported?

PNG and WebP can retain transparency. JPEG uses a white background. Only static images are supported; animated PNG, GIF and animated WebP are outside this release.

Are images uploaded or original metadata preserved?

Both the base image and logo are processed locally. Export creates a new image without retaining source metadata.
