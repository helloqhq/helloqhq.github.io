SVG Optimizer

Optimize static SVG in your browser with before-and-after previews and byte counts. Adjust precision, retain viewBox and IDs, and copy or download without uploads.

About this tool

Paste or import static SVG and optimize it with SVGO in a dedicated worker. Remove comments and editor metadata, simplify numbers, colors and paths, then compare previews and UTF-8 byte counts.

The optimizer retains viewBox, IDs, titles and descriptions. Input is never inserted directly into the page DOM. Lower numeric precision can alter fine detail, so review the result before downloading.

Best use cases

  • Reduce SVG code for website icons and static illustrations.
  • Remove comments and metadata from design-tool exports.
  • Compare file size and visual detail at different numeric precisions.

How to use it

  1. Paste a complete SVG or import a UTF-8 .svg file.
  2. Choose 2–6 decimal places and select Optimize SVG.
  3. Compare the previews and sizes, then copy or download the result.

Scope and limits

  • Up to 200,000 characters and 10,000 elements. A complete static document with the SVG namespace is required.
  • Scripts, events, animation, foreignObject, DOCTYPE, embedded images, external resources, CSS at-rules and escape sequences are rejected.
  • Only document-local #id references are supported. Precision changes can affect details; an already small file may not shrink further.

Data processing

Parsing and optimization run in a local worker, without uploading SVG or loading its external resources.
