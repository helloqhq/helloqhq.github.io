CSS Formatter & Minifier

Format and conservatively minify CSS locally with indentation options, syntax error positions, UTF-8 byte counts, size changes, copy and download. No uploads.

About this tool

Format standard CSS or reduce syntax spacing and ordinary comments. Minification retains rule and declaration order, fallback declarations, custom properties and values. Compare UTF-8 sizes, then copy or download .css output.

Best use cases

  • Read minified styles and tidy CSS snippets for code reviews and documentation.
  • Reduce stylesheet size while preserving fallback declarations and calc() expressions.

How to use it

  1. Paste standard CSS and choose 2/4-space or Tab indentation.
  2. Select Format or Minify. Syntax errors report source positions. Each run supports 200,000 characters and can be cancelled.
  3. Compare sizes and inspect the output, then copy or download .css. Resources in @import or url() are never loaded.

FAQ

Does minification merge rules or change values?

No. This release conservatively reduces syntax spacing and ordinary comments, retaining license comments, declaration order, duplicate fallbacks, custom properties and required calc() spacing.

Does successful parsing establish valid styles?

No. Parsing can identify unclosed structures and missing colons, without checking every property, value or browser compatibility. Styles are never executed.

Are SCSS and Less supported?

Only standard CSS is supported. Compile preprocessors in your project, then paste the resulting CSS.
