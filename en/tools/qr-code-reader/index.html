QR Code Reader

Decode a QR code from a PNG, JPEG or WebP image or screenshot. Choose, drop or paste an image and copy the decoded text locally without uploads or opening links.

About this tool

Choose, drop or paste a QR image to read its link or text locally in your browser. This page reads existing QR images; use the separate QR generator to create a code.

Best use cases

  • Read a QR code in a screenshot, document image or saved picture.
  • Inspect the original text encoded in a QR code before opening a link.

How to use it

  1. Choose, drop or paste one static PNG, JPEG or WebP image. Limits: 20 MiB, 24 megapixels and 8,192 pixels per side.
  2. The image is scanned automatically for one QR code. Cancel, scan again or choose another image as needed.
  3. Inspect and copy the decoded content. Links remain text and are never opened automatically.

FAQ

Are decoded links safe?

Decoding only recovers encoded content; it does not verify trust or link safety. Links never open automatically.

Why might scanning fail?

Tiny, obscured, blurred or dense QR codes may fail. Images longer than 2,500 pixels are scaled down; crop closer to the code and try again. Not every QR code can be read.

Are cameras, barcodes or batches supported?

This release reads one QR code from one static image, without camera, barcode, animation or batch support.
