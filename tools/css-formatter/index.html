CSS格式化与压缩

本地 CSS 格式化与保守压缩，支持缩进设置、语法错误行列、UTF-8字节数及体积变化、复制下载，保留声明顺序和回退规则，样式不上传。

工具介绍

格式化标准 CSS，或精简语法空白和普通注释。压缩保持规则和声明顺序、重复回退声明、自定义属性及属性值；可比较 UTF-8 字节数，复制或下载 .css 文件。

适用场景

  • 阅读压缩样式，整理代码评审和文档中的 CSS 片段。
  • 在保留回退声明和 calc() 表达式的前提下缩小样式文件。

使用步骤

  1. 粘贴标准 CSS，选择 2/4 空格或 Tab 缩进。
  2. 点击格式化或压缩；语法错误会提示行列位置。单次上限 200,000 字符，可取消。
  3. 比较体积、检查结果，再复制或下载 .css 文件。不会加载 @import 或 url() 中的资源。

常见问题

压缩会合并规则或改变属性值吗？

不会。首版使用保守压缩，只整理语法空白和普通注释，保留许可注释、声明顺序、重复声明、自定义属性及 calc() 所需空白。

语法解析通过代表样式有效吗？

不代表。解析可以发现未闭合结构、缺少冒号等问题，不检查所有属性名、属性值或浏览器兼容性，也不运行样式。

支持 SCSS 和 Less 吗？

首版只支持标准 CSS。请先在项目中编译预处理语言，再粘贴 CSS 结果。
