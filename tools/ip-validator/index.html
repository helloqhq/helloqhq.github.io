IP地址合法性检测

纯前端 IP 地址合法性检测工具，支持单条与批量 IPv4、IPv6 格式校验，显示地址类型、错误原因和统计，可复制结果。输入在浏览器本地处理，无需上传。

工具介绍

粘贴一个 IP 地址，或每行一个批量输入 IPv4 与 IPv6 地址，查看格式是否合法、地址类型和具体错误原因。所有校验均在浏览器本地完成，输入不会上传。

IPv4 采用四段 0–255 的十进制写法，多位数字不允许前导零。IPv6 支持完整格式、一次 :: 压缩、大小写十六进制及 IPv4 嵌入形式。格式合法不代表地址已分配或能够连接。

适用场景

  • 检查配置文件、日志或文档中的 IP 地址格式。
  • 批量核对 IPv4 与 IPv6 地址列表，定位原始行号和错误原因。

使用步骤

  1. 输入纯 IP 地址，每行一条；首尾空白和空行会自动忽略，重复条目保留。
  2. 点击检测，查看总条数、合法与不合法数量，以及每行的结果和说明。
  3. 复制检测结果，或修改输入后重新检测。

常见问题

支持 CIDR、端口和接口标识吗？

仅接受纯 IP 地址。192.168.1.1/24、192.168.1.1:80、[::1]、fe80::1%eth0 和完整 URL 会提示移除扩展部分。

私有地址、回环地址和特殊用途地址是否合法？

只要格式正确就合法。此工具不判断公网归属、地址分配状态或网络连通性。

IPv6 必须采用最短的小写形式吗？

不需要。大写、前导零和未压缩写法均可合法；:: 最多出现一次且必须代替至少一组零。IPv4 嵌入尾部占两组。
