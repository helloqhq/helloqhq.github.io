HTML格式化与压缩

在浏览器本地格式化或保守压缩 HTML 文档和片段，支持缩进设置、UTF-8体积对比、复制与下载，不执行源码、不上传内容。

工具介绍

将 HTML 文档或片段整理为可读的缩进格式，或保守压缩空白与普通注释。查看输入输出的 UTF-8 字节数和体积变化，再复制或下载 .html 文件。

适用场景

  • 阅读压缩网页源码，整理静态页面和文档中的 HTML 示例。
  • 在保留内联文本间空格和预格式化内容的前提下精简 HTML。

使用步骤

  1. 粘贴标准 HTML 文档或片段，选择 2/4 空格或 Tab 缩进。
  2. 点击格式化或压缩，查看处理结果及体积变化。每次最多 200,000 个字符，可取消。
  3. 检查关键文本空白后，复制或下载 .html 文件。输入源码不会执行或加载外部资源。

常见问题

会压缩内嵌 JavaScript 和 CSS 吗？

压缩时保留 script/style 内部代码，避免联动优化。格式化采用默认 HTML 显示规则，不提供运行预览。

文本空白如何处理？

保守压缩将普通空白折叠为单个空格，保留内联文本间的分隔、pre/textarea 内容和许可或条件注释。自定义 white-space 样式可能改变空白含义，交付前请核对结果。

支持框架模板和完整校验吗？

首版面向标准 HTML，不承诺 JSX、Vue/Svelte 或服务端模板。解析诊断不等于完整的 HTML 标准、可访问性或运行结果校验。
