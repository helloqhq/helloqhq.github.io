JSON转SQL

将 JSON 对象或数组转换为 MySQL、PostgreSQL 或 SQLite 的 CREATE TABLE 与 INSERT 语句，综合全部行推断字段类型，安全转义字符串。浏览器本地处理，不上传数据。

工具介绍

粘贴一个 JSON 对象或对象数组，即可生成建表语句和批量 INSERT 语句。支持 MySQL、PostgreSQL 与 SQLite，并按所选方言正确引用表名和字段名。

字段类型综合全部行推断：整数、小数、布尔与文本分别映射到对应类型，缺失字段写入 NULL，嵌套对象和数组保存为 JSON 文本。字符串安全转义，可放心导入测试库核对。

适用场景

  • 把接口返回的 JSON 样例导入测试数据库。
  • 根据 JSON 数据快速起草建表语句。
  • 为测试环境批量生成 INSERT 初始化数据。

使用步骤

  1. 粘贴 JSON 对象或数组，或点击示例。
  2. 填写表名，选择 SQL 方言和输出内容。
  3. 点击转换，核对字段类型后复制或下载 .sql 文件。

能力范围与限制

  • 最多 200,000 字符、1,000 行、200 列，JSON 最多 40 层嵌套；不支持仅大小写不同的同名字段。
  • 不自动创建主键、索引或约束，类型推断仅基于当前样本，导入前请结合业务核对。
  • 超出 JavaScript 安全整数范围的数字会被拒绝，大整数请使用字符串表示。

数据处理说明

JSON 解析与 SQL 生成在浏览器本地 Worker 中完成，不连接数据库，不上传或保存数据。
