文件哈希校验

本地计算文件 MD5、SHA-1、SHA-256、SHA-512 摘要，支持拖拽文件、分块计算、进度与取消、期望摘要比对。文件不上传。

工具介绍

选择或拖入本地文件，按原始字节计算 MD5、SHA-1、SHA-256 或 SHA-512。支持分块处理、进度和取消，可粘贴期望摘要进行比对，文件不上传。

适用场景

  • 核对下载的软件包或压缩包与发布方提供的摘要是否一致。
  • 比较不同文件副本的内容摘要，排查传输或存储中的变化。

使用步骤

  1. 选择或拖入一个文件，勾选至少一种哈希算法。
  2. 点击计算文件哈希，查看进度；大文件可随时取消。
  3. 复制结果，或粘贴期望的十六进制摘要以比对。忽略摘要大小写和首尾空白。

常见问题

与文本哈希有什么区别？

此工具读取文件原始字节，不做文本解码，也不把文件名作为输入。非文本文件、编码及换行差异都会按实际字节反映在摘要中。

文件会上传吗？

不会。文件在浏览器 Worker 中分块计算，取消会终止当前计算。

摘要一致代表文件可信吗？

摘要用于完整性比对，不能单独证明文件来源可信。应从可信来源取得期望摘要。
