数据与 JSON

JSON随机生成器

在线随机生成合法 JSON 对象或数组，可设置最大嵌套深度、每层元素数和美化/紧凑输出。支持节点限制、语法高亮、复制和下载，全部在浏览器本地完成。

工具介绍

为前端页面、接口示例和测试演示快速生成随机 JSON。可指定根节点为对象或数组，并控制嵌套深度、每个容器的元素数量以及输出格式。

生成内容覆盖对象、数组、字符串、数字、布尔值和 null。总节点预算会限制组合增长，达到上限时提前结束当前层，确保输出始终可被 JSON 解析。

适用场景

  • 为列表、详情页或空状态制作不同结构的模拟数据。
  • 检查前端解析、折叠、搜索和格式化功能是否能处理嵌套 JSON。
  • 生成可重复调整的演示样例，用于教学、截图或接口文档草稿。

使用步骤

  1. 选择根节点类型、最大深度、每层最大元素数和输出格式。
  2. 点击生成 JSON，在只读高亮编辑器中查看结果与数据节点统计。
  3. 调整参数可重新生成，随后复制结果或下载 .json 文件。

能力范围与限制

  • 最大深度为 1–8，根容器计为第 1 层；每个对象或数组包含 1–10 个元素。
  • 每次最多生成 5,000 个数据节点和 500,000 个输出字符。
  • 结果仅用于测试和演示，不包含真实个人信息，也不适合作为安全令牌或密码。

数据处理说明

参数校验、随机数据生成、复制和下载均在浏览器本地完成，不依赖后端，也不上传任何内容。

常见问题

生成的数据一定是合法 JSON 吗？

是。工具使用 JSON.stringify 输出对象、数组和标准 JSON 值，不会生成注释、函数、undefined 或循环引用。

深度和元素数都调大后会不会卡住？

工具有 5,000 个总节点和 500,000 个字符的硬限制，达到节点预算会停止继续扩展当前层，以避免指数增长。

随机内容适合做密码或安全令牌吗？

不适合。这里使用普通随机数生成演示数据，没有密码学安全保证，请使用专门的密码或令牌生成工具。
