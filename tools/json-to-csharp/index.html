JSON转C#

将 JSON 转换为 C# 实体类，递归生成嵌套类与 List 集合，综合数组全部元素推断类型，支持 Newtonsoft.Json 与 System.Text.Json 特性、可空类型标注。浏览器本地生成，不上传数据。

工具介绍

粘贴接口返回的 JSON 样例，即可生成可直接使用的 C# 实体类。嵌套对象递归生成独立类，数组生成 List<T> 集合，并综合数组中全部元素合并字段与类型，缺失字段自动标注可空。

支持 Newtonsoft.Json 的 [JsonProperty] 与 System.Text.Json 的 [JsonPropertyName] 两种映射特性，属性名默认 PascalCase，也可保留原始键名；整数按范围映射 int/long，小数映射 double。

适用场景

  • 把接口文档或抓包得到的 JSON 快速转成 C# 反序列化模型。
  • 为 .NET 项目起草 DTO、实体类或配置模型。
  • 对照 JSON 样例检查字段类型与可空性，减少手写遗漏。

使用步骤

  1. 粘贴 JSON 对象或数组，页面已预置示例。
  2. 填写根类型名称，选择序列化特性、属性命名与可空类型选项。
  3. 点击“生成 C#”，核对生成代码后复制或下载 .cs 文件。

能力范围与限制

  • JSON 最多 40 层嵌套、20,000 个节点；根节点需为对象或数组。
  • 数字使用 JavaScript 精度，超出安全整数范围的大整数请用字符串表示。
  • 类型推断仅基于当前样本，混合类型字段回退为 object，导入项目前请结合业务复核。

数据处理说明

JSON 解析与代码生成全部在浏览器本地完成，不上传或保存数据。

常见问题

数组里字段不一致的对象怎么处理？

工具会合并数组中全部对象的字段：共同字段保留，部分对象缺失的字段标注为可空（如 int?），类型冲突时自动拓宽（int→long→double）或回退为 object。

应该选 Newtonsoft.Json 还是 System.Text.Json？

项目使用 Json.NET（Newtonsoft.Json）时选 [JsonProperty]；.NET Core 3.0+ 内置序列化器选 [JsonPropertyName]。两者只在属性名与 JSON 键不一致时生成。

JSON 数据会被上传吗？

不会。解析与代码生成全部在浏览器本地运行，关闭页面后不留存任何输入。
