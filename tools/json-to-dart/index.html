JSON转Dart

将 JSON 转换为 Dart 类，递归生成嵌套类与 List 集合，综合数组元素推断类型，支持 null 与缺失字段可空标注、自定义根类名和私有字段。浏览器本地生成，不上传数据。

工具介绍

粘贴 JSON 样例，快速生成 Dart 类定义。嵌套对象会生成独立类，数组生成 List<T>，并综合数组中全部对象合并字段，便于起草 Flutter 模型、接口数据类型和测试样例。

出现 null 或在部分数组元素中缺失的字段会标注为可空类型；整数、小数、布尔值与字符串分别映射为 int、double、bool 和 String，混合类型回退为 Object?。

适用场景

  • 把接口返回的 JSON 快速转成 Dart 或 Flutter 数据模型。
  • 为 Dart 项目起草 DTO、配置模型或测试数据结构。
  • 对照 JSON 样例检查字段类型、集合结构和可空性，减少手写遗漏。

使用步骤

  1. 粘贴 JSON 对象或对象数组，页面提供示例。
  2. 填写根类名，并按需勾选私有字段。
  3. 点击“生成 Dart”，核对代码后复制或下载 .dart 文件。

能力范围与限制

  • 单次最多 200,000 字符、40 层嵌套和 20,000 个节点；根节点需为对象或数组。
  • 数字使用 JavaScript 精度，超出安全整数范围的数值请在 JSON 中使用字符串。
  • 类型推断仅基于当前样例；生成代码不包含 JSON 序列化逻辑，导入项目前请结合业务复核。

数据处理说明

JSON 解析与 Dart 代码生成全部在浏览器本地完成，不上传或保存数据。

常见问题

数组里字段不一致的对象怎么处理？

工具会合并全部数组元素的字段。部分元素缺失的字段标注为可空类型；数值冲突会拓宽为 double，其他类型冲突回退为 Object?。

私有字段选项会改变什么？

生成字段会添加下划线前缀，例如 userName 变为 _userName。类名与构造参数会同步调整，便于控制 Dart 类内部的字段可见性。

JSON 数据会被上传吗？

不会。解析和代码生成全部在浏览器本地运行，关闭页面后不会保留输入。
