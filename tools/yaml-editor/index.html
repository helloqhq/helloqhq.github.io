YAML校验与格式化

本地 YAML/YML 语法校验、格式化与 YAML 转 JSON，支持错误行列、缩进设置、复制及下载。采用 YAML 1.2 Core 单文档规则，内容不上传。

工具介绍

编辑 YAML 或 YML 配置，检查缩进、重复键和语法问题，再格式化或转换为 JSON。支持 2/4 空格缩进、错误定位、复制与下载；所有处理均在浏览器本地完成。

适用场景

  • 排查 Docker Compose、Kubernetes 和 CI 配置中的 YAML 语法问题。
  • 整理配置片段，或将 YAML 数据转为 JSON 供接口调试使用。

使用步骤

  1. 粘贴单个 YAML 1.2 Core 文档，或加载示例。每次最多 200,000 个字符。
  2. 选择缩进，点击校验语法、格式化或转为 JSON；按错误行列修正输入。
  3. 复制或下载 .yaml/.json 结果。输入变化会清除旧结果，处理期间可取消。

常见问题

校验通过代表配置可以部署吗？

不代表。这里只检查 YAML 语法及支持范围，不校验 Kubernetes 资源字段、Docker Compose 版本、CI 平台规则或部署结果。

哪些内容不能转换成 JSON？

循环引用、非字符串映射键、超出安全精度的整数、NaN、Infinity 和负零会报错；需保留为文本的编号应加引号。别名展开、嵌套深度和输出体积均有限制。

支持多个文档、特殊标签和日期吗？

首版仅支持 YAML 1.2 Core 单文档，不支持自定义标签或扩展类型。普通日期文本保持字符串，格式化会保留注释和锚点含义。
