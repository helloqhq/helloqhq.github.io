UserAgent生成器

从 Mac Chrome、Windows Edge、iPhone Safari 三个预设中随机生成 User-Agent 字符串，便于复制到解析器测试和文档。版本为固定样例，不代表最新浏览器。

内容核对：2026-09-30

工具介绍

点击生成，从 Mac Chrome、Windows Edge 和 iPhone Safari 三个内置 User-Agent 样例中随机选取一个，可复制到测试数据或文档。

样例版本固定；工具不检测当前浏览器，不维护实时版本库，也不提供浏览器字段配置。

适用场景

  • 为浏览器标识解析器准备测试样例。
  • 说明 User-Agent 中的平台、引擎和浏览器标识字段。

使用步骤

  1. 点击生成，随机选择预设样例。
  2. 检查平台和版本字段；需要其他样例时再次生成。
  3. 点击复制结果，将字符串放入测试数据。

可能的输出：iPhone Safari

输出

Mozilla/5.0 (iPhone; CPU iPhone OS 18_2 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/18.2 Mobile/15E148 Safari/604.1

iPhone 表示设备系列，AppleWebKit 为引擎标识，Version/18.2 与 Safari/604.1 为样例浏览器字段。运行也可能返回另外两个预设。

能力范围与限制

  • 只有三个固定预设，连续运行可能返回同一个字符串。
  • 修改请求头不能模拟浏览器内核或设备。UA 可以被简化或伪装，能力判断应使用特性检测。

数据处理说明

样例在浏览器内选取，不请求外部浏览器版本服务。

常见问题

能指定浏览器或版本吗？

当前只有三个随机选取的固定预设。测试需要其他版本时，请编辑复制后的样例。

UA 能证明浏览器支持某个功能吗？

不能。请求头只是字符串，判断能力应直接检测所需功能。
