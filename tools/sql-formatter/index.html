SQL格式化

本地 SQL 格式化与语法检测工具，支持 MySQL、PostgreSQL、SQLite，提供高亮、行号、错误位置、查找替换、撤销和下载。代码不上传、不执行。

工具介绍

粘贴 SQL，选择数据库方言、缩进和关键字大小写，使用语法高亮、行号与查找替换完成编辑。可分别格式化与检测语法、定位解析问题，再复制、下载或应用结果。所有处理在浏览器本地完成。

适用场景

  • 整理日志或接口调试中复制的 SQL，阅读关联查询与子查询。
  • 统一文档和代码评审中 SQL 的缩进及关键字大小写。
  • 按方言检测输入中的语法问题，并根据行列提示定位修改。

使用步骤

  1. 输入 SQL，并选择 MySQL、PostgreSQL 或 SQLite 方言。
  2. 点击格式化，或使用 Shift + Alt + F；按 Ctrl/Cmd + F 查找替换。点击检测语法，可查看解析状态及行列位置。
  3. 复制或下载 .sql 文件，或应用结果回输入区并按需撤销。每次最多处理 200,000 个字符。

常见问题

会连接数据库或执行 SQL 吗？

不会。格式化只在浏览器本地处理文本，不上传 SQL，也不连接数据库。

语法检测通过是否代表 SQL 能执行？

不代表。检测只说明当前方言解析器能识别语句，不验证表、字段、权限或执行结果。部分数据库扩展语法可能无法识别，因此检测与格式化独立。
