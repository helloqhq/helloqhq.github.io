XML-JSON互转

XML与JSON双向转换在线工具，支持属性、文本、重复节点和数组映射，提供引号转义、复制与下载。所有转换均在浏览器本地完成，不上传数据。

工具介绍

在同一工作区完成 XML 转 JSON 与 JSON 转 XML。XML 属性映射为 -属性名，文本映射为 #text，重复子节点自动合并为数组，便于接口联调、配置迁移和数据样例整理。

JSON 中的数组会生成同名 XML 节点，对象中的 -属性名会写成 XML 属性。文本中的 &、<、> 等字符会正确转义，也可选择将双引号转为 &quot;。

适用场景

  • 把 XML 接口响应整理成 JSON，继续用于前端调试或测试数据。
  • 将 JSON 配置或对象数组转成 XML，检查标签、属性和层级结构。
  • 在迁移旧系统数据时快速生成结构样例，再由开发或测试人员复核。

使用步骤

  1. 在左侧粘贴 JSON，或在右侧粘贴 XML，也可以加载示例。
  2. 点击 JSON → XML 或 XML → JSON，另一侧会显示转换结果。
  3. 核对属性、文本和数组映射，随后复制或下载对应格式的文件。

能力范围与限制

  • 单次最多 200,000 字符、40 层嵌套和 20,000 个节点。
  • JSON 顶层必须是对象；XML 属性值仅支持字符串、数字、布尔值或 null。
  • 不支持 DTD 与实体声明；XML 标签名需符合 XML 命名规则。

数据处理说明

解析、转换、复制和下载均在浏览器本地完成，不上传、保存或执行输入内容。

常见问题

XML 属性和文本会怎么转换？

属性使用 - 前缀，例如 id="7" 转为 "-id": "7"；元素文本使用 #text。没有属性或子节点的空元素会保留为空字符串。

重复的 XML 节点会丢失吗？

不会。同名子节点会自动合并为数组；JSON 数组转 XML 时会生成多个同名标签。

转换会上传数据吗？

不会。XML 解析和 JSON 生成全部在当前浏览器内完成，不依赖后端接口。
