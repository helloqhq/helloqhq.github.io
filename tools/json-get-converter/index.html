JSON与GET参数互转

JSON 与 GET 请求参数双向转换在线工具，支持点号与方括号嵌套、URL 编码解码、完整 URL 解析、重复参数数组合并、复制与下载。全部在浏览器本地完成，不上传数据。

工具介绍

在 JSON 对象与 GET 请求参数之间双向转换。JSON 嵌套对象使用点号展开，数组使用 [0]、[1] 索引，生成适合接口联调的 query string；反向转换时可还原嵌套对象与数组。

支持粘贴完整 URL、? 开头的查询串或裸参数。参数名和值默认进行 URL 编码，转换时自动处理中文、空格、&、= 等字符；重复参数保留为数组，避免静默丢失。

适用场景

  • 把接口文档中的 JSON 请求样例快速转成 GET 参数，用于浏览器、cURL 或调试工具验证。
  • 把抓包或日志中的完整请求 URL 还原为 JSON，检查参数层级、重复值和空参数。
  • 整理前端埋点、搜索条件与分页参数，生成可复制的 query string。

使用步骤

  1. 在 JSON 或 GET 参数区域粘贴内容，也可以点击示例同时查看两种格式。
  2. 需要时切换 URL 编码与嵌套还原选项，然后点击 JSON → GET 或 GET → JSON。
  3. 核对参数数量、重复参数和跳过的空容器，随后复制或下载对应内容。

能力范围与限制

  • 单次最多 200,000 个字符、40 层嵌套和 20,000 个参数。
  • GET 参数值默认保留为字符串；JSON 中的数字、布尔值和 null 会转成对应文本。
  • 空对象与空数组会跳过并计数；数组索引必须从 0 连续填写，冲突路径会明确报错。

数据处理说明

JSON 解析、URL 编解码、结构还原、复制与下载均在浏览器本地完成，不上传、保存或执行输入内容。

常见问题

嵌套对象和数组怎么表示？

默认使用 filter.status=ok 表示嵌套对象，使用 tags[0]=json 表示数组；GET 转 JSON 时会按点号和方括号还原结构。JSON 键名中的字面点号与方括号会被编码，避免与路径语法混淆。

重复参数会丢失吗？

不会。同一个参数出现多次时，JSON 中会保存为字符串数组，例如 dup=1&dup=2 转为 "dup": ["1", "2"]。若同一路径同时作为值和容器，则停止转换并提示冲突。

数据会上传吗？

不会。解析、编码、嵌套还原与文件生成全部在当前浏览器内完成，不依赖后端接口。
