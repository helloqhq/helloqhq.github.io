XPath在线测试

在线测试 XPath 1.0 表达式，支持 HTML/XML 文档、可选上下文节点、元素、属性、文本以及 count()、string()、boolean() 标量结果。本地解析，可复制和下载。

工具介绍

粘贴 HTML 或 XML 文档，输入 XPath 表达式并立即查看匹配结果。工具使用浏览器原生 XPath 1.0 引擎，支持节点集合、属性、文本、注释以及 count()、string()、boolean() 等标量返回值。

可以通过另一个 XPath 表达式指定上下文节点，再用相对路径查询。输入文档不会注入当前页面，脚本不会执行，匹配内容只以文本形式展示。

适用场景

  • 验证从网页或 XML 接口复制的节点路径，检查属性与文本提取结果。
  • 在爬虫、数据转换或自动化脚本编写前确认 XPath 表达式是否正确。
  • 对比节点数量和标量返回值，快速定位条件筛选与上下文路径问题。

使用步骤

  1. 选择 HTML 或 XML 模式，粘贴文档并加载对应示例。
  2. 输入 XPath 表达式；需要相对查询时，可选填上下文节点表达式。
  3. 点击测试匹配，核对节点或标量结果，然后复制或下载文本。

能力范围与限制

  • 文档最多 200,000 字符，每个表达式最多 4,000 字符，最多展示 200 个匹配节点。
  • 仅支持浏览器提供的 XPath 1.0，不支持 XPath 2.0/3.0 函数与自定义命名空间解析器。
  • XML 模式拒绝 DTD 与实体声明；单个节点内容过长时会截断显示。

数据处理说明

文档解析与 XPath 求值均通过浏览器原生 DOMParser 和 document.evaluate 在本地完成。文档不上传，脚本不会执行，结果以安全文本展示。

常见问题

为什么表达式没有匹配到节点？

请检查文档类型、标签大小写、命名空间、路径起点以及上下文节点。HTML 模式会按 HTML 规则解析，XML 模式要求文档格式正确。

上下文节点怎么使用？

先输入一个只匹配单个节点的 XPath，例如 //catalog，再让主表达式使用 book/title 这样的相对路径。上下文没有匹配到节点时会明确提示。

文档中的脚本会执行吗？

不会。文档只用于本地 XPath 求值，不会注入当前页面，匹配结果也只作为文本展示。
