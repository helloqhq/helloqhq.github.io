PlantUML编辑器

编辑 PlantUML 单个图块，使用模板并通过公共 PlantUML 服务自动预览 PNG 或 SVG，支持复制源码和图像链接。预览需要发送编码后的源码到外部服务。

内容核对：2026-09-30

工具介绍

编辑单个 PlantUML 图块并预览 PNG 或 SVG。可选择模板开始绘图；预览前会检查开始与结束标记是否配对。

图像由 plantuml.com 公共服务渲染，源码会编码到请求 URL 中；编码不等于保密。

适用场景

  • 为技术说明绘制时序图。
  • 预览模板并分享渲染图像链接。

使用步骤

  1. 选择模板，或粘贴一组类型相匹配的 @start... / @end... 图块。
  2. 识别有效图块后等待自动外部预览，按需选择 PNG 或 SVG。
  3. 复制源码或预览链接，也可打开图像后使用浏览器保存。

包含两条消息的时序图

输入

@startuml
Alice -> Bob: Hello
Bob --> Alice: Hi
@enduml

预览中 Alice 向 Bob 发送 Hello，Bob 返回 Hi。将此图块粘贴到编辑器；PNG 与 SVG 表示同一张图。

能力范围与限制

  • 一次预览一个图块，本地标记检查不等于完整 PlantUML 语法校验。
  • 图像加载成功只表示收到图像，服务也可能返回错误图；请检查实际内容。
  • 预览依赖外部服务和网络，不应在公共渲染流程中输入机密图表内容。

数据处理说明

源码编辑在本地进行；自动预览会将编码后的源码通过 URL 发送到 https://www.plantuml.com/plantuml，浏览器或服务可能保留该地址，因此不是全部本地渲染。

常见问题

预览在本地渲染吗？

不是。编辑器通过包含编码源码的 URL 向公共 PlantUML 服务请求 PNG 或 SVG。

标记配对正确，为什么仍显示错误图？

本地检查仅覆盖图块标记，不验证全部 PlantUML 指令。外部渲染器仍可能在图像中报告语法错误。
