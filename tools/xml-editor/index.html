XML编辑器

在浏览器内编辑、格式化和压缩 XML，检查标签语法、定位错误、筛选节点路径，支持文件导入、复制与下载。不提供 XSD 或 DTD 校验。

内容核对：2026-09-30

工具介绍

支持 XML 语法高亮、格式化、压缩和节点路径浏览。校验用于检查文档是否符合 XML 基本语法；解析失败时尽可能提示错误位置。

选择路径可复制路径并预览节点值。路径列表展示解析后的结构，不是完整 XPath 查询引擎。

适用场景

  • 检查配置文件或 XML 接口响应。
  • 在交付文档前定位没有闭合的标签。

使用步骤

  1. 粘贴 XML、导入文件或加载内置示例。
  2. 选择格式化或校验，先修正语法错误。
  3. 筛选路径并选择节点预览内容；复制或下载当前文档。

格式化语法正确的 XML

输入

<root><item id="1">Hello</item></root>

输出

<root>
  <item id="1">Hello</item>
</root>

此结构标签闭合正确。<root><item></root> 缺少 item 的结束标签，会校验失败。

能力范围与限制

  • 只检查 XML 基本语法，不验证 XSD、DTD 或业务数据约束。
  • 节点路径查看不是完整 XPath 执行。格式化会改变空白；文本空格有语义时，请检查输出再导出。

数据处理说明

XML 解析和编辑在浏览器内完成；持久保存草稿需要偏好同意，文件内容不会进入统计参数。

常见问题

能用 XSD 校验文档吗？

不能。此处检查 XML 解析与标签结构，XSD 或 DTD 约束需要专门的模式校验器。

常见 XML 校验错误有哪些？

包括标签不配对、属性值未加引号、多个根元素或未转义的 &。请结合报错位置检查附近内容。
