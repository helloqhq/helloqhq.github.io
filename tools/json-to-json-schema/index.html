JSON转JSON Schema

根据 JSON 样本自动生成 JSON Schema Draft-07，合并数组中全部对象的字段与类型，可设置共同字段必填与是否允许额外字段。浏览器本地处理，不上传数据。

工具介绍

粘贴 JSON 样本即可推断对应的 JSON Schema（Draft-07）。工具会遍历全部数组元素，合并对象字段，区分整数与小数，并用 anyOf 表示混合类型。

可选择把同组样本中每次都出现的字段设为必填，并设置是否允许额外字段。生成结果可作为接口文档、表单校验或配置校验的起点。

适用场景

  • 根据接口响应样例起草 JSON Schema 文档。
  • 为配置文件或表单数据准备校验规则。
  • 检查同一数组中对象字段和类型是否一致。

使用步骤

  1. 粘贴 JSON 样本，或点击示例。
  2. 选择必填字段规则和额外字段策略。
  3. 点击转换，人工复核后复制或下载 schema.json。

能力范围与限制

  • 最多 200,000 字符、40 层嵌套和 20,000 个节点。
  • 只能根据样本推断结构，不能推断格式、取值范围、枚举等业务规则；空数组不限制元素类型。
  • 本工具只生成 Schema，不用 Schema 校验数据；超出 JavaScript 安全整数范围的数字会被拒绝。

数据处理说明

JSON 解析与 Schema 推断在浏览器本地 Worker 中完成，不上传或保存数据。
