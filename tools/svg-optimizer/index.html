SVG压缩

粘贴或导入静态 SVG，在浏览器本地压缩代码、调整小数精度，对比预览与文件体积并复制或下载。保留 viewBox 和 ID，拒绝脚本与外部资源。

工具介绍

导入或粘贴静态 SVG，使用 SVGO 在独立 Worker 中移除注释、编辑器元数据并优化数值、颜色和路径。优化后可对比代码、预览与 UTF-8 字节数。

保留 viewBox、ID、标题和描述，不直接将输入插入页面 DOM。降低小数精度可能影响细节，下载前请检查前后预览。

适用场景

  • 精简网站图标和静态插画的 SVG 代码。
  • 清理设计软件导出文件中的注释与元数据。
  • 比较不同小数精度对文件体积和细节的影响。

使用步骤

  1. 粘贴完整 SVG 或导入 UTF-8 编码的 .svg 文件。
  2. 选择 2–6 位小数精度，点击压缩 SVG。
  3. 对比结果及体积，复制代码或下载优化后的文件。

能力范围与限制

  • 最多 200,000 字符和 10,000 个元素，仅支持含 SVG 命名空间的完整静态文档。
  • 拒绝脚本、事件、动画、foreignObject、DOCTYPE、嵌入图片、外部资源及 CSS @规则和转义写法。
  • 资源引用仅支持文档内 #id；精度调整可能改变细节，已精简的文件不保证进一步缩小。

数据处理说明

解析与优化在本地 Worker 中执行，不上传 SVG，不加载 SVG 内的外部资源。
