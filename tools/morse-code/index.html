摩斯密码

摩斯密码在线转换器，支持文本与摩尔斯电码互转、中文转拼音后编码、标准时序音频试听（速度/音调/音量可调）、逐字母高亮与电码对照表，浏览器本地处理。

工具介绍

输入文本或摩尔斯电码，实时完成双向转换。采用国际电信联盟（ITU）国际摩斯电码，覆盖 A-Z、0-9 与常用标点；字母间用空格分隔，单词间用 / 或三个空格分隔。

中文可先按无声调拼音编码（如“你好”→ NI HAO），多音字按词组语境匹配。生成的电码可按标准时序试听：点 1 单位、划 3 单位、字母间隔 3 单位、单词间隔 7 单位，速度、音调、音量均可调，播放时逐字母高亮。

适用场景

  • 把文字转成摩斯电码，用于游戏解谜、暗号或趣味创作。
  • 解码收到的摩尔斯电码，核对点划与分隔是否规范。
  • 通过音频试听学习摩斯电码的节奏与听辨。

使用步骤

  1. 选择转换方向，输入文本或电码，结果实时生成。
  2. 编码时可选中文处理方式、单词分隔符与不支持字符的处理策略。
  3. 点击播放试听电码，调节速度、音调与音量，然后复制或下载结果。

能力范围与限制

  • 单次最多 20,000 字符；试听最多 500 个字母，更长电码请分段播放。
  • 电码表不含汉字，中文按拼音编码后不可无损还原为原汉字。
  • 解码默认输出大写字母；未知电码可报错或替换为 ?。

数据处理说明

转换与音频合成全部在浏览器本地完成，不上传内容。

常见问题

中文怎么转摩斯密码？

国际摩斯电码没有汉字。工具默认先把中文转成无声调拼音再编码，例如“你好世界”→ NI HAO SHI JIE；也可以选择忽略汉字只编码其余字符。

点和划用什么符号输入？

点支持 . · • * ．，划支持 - — – −，解码时会自动规范化。字母之间用空格分隔，单词之间用 / 或三个及以上空格分隔。

SOS 的摩斯电码是什么？

SOS 编码为 ... --- ...，即三短、三长、三短，是国际通用的求救信号。
