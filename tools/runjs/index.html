RunJS在线编辑器

RunJS 在线编辑器支持 HTML、CSS、JavaScript 三栏编写、手动或自动运行、沙箱预览、控制台、全屏与 ZIP 下载。代码仅在浏览器本地执行，不上传。

工具介绍

在同一个工作区编写 HTML、CSS 和 JavaScript，立即查看页面效果。支持手动运行、停止改动后的自动运行、全屏预览以及 console.log 等控制台输出，适合快速验证前端片段。

预览运行在禁用同源访问的沙箱 iframe 中，并通过内容安全策略限制外部资源、网络请求、弹窗和表单提交。代码不会发送到服务器，也不需要安装本地运行环境。

适用场景

  • 快速验证 HTML 结构、CSS 样式和 JavaScript 事件是否按预期配合。
  • 复现页面布局或交互问题，缩小为可分享、可下载的最小示例。
  • 编写教学演示和临时原型，检查控制台输出与运行时异常。

使用步骤

  1. 分别编辑 HTML、CSS 与 JavaScript，也可以加载完整示例。
  2. 点击运行，或开启自动运行；在全屏预览中检查桌面与窄屏效果。
  3. 在控制台排查错误，随后下载包含 index.html、style.css 和 script.js 的 ZIP。

能力范围与限制

  • 每个编辑器最多 100,000 字符，三个编辑器合计最多 300,000 字符。
  • 外部图片、字体、接口请求与跨域脚本默认被阻止；需要这些资源时请在本地环境运行。
  • 同步死循环可能阻塞浏览器页面，请避免 while(true) 等无法让出执行线程的代码。

数据处理说明

代码在浏览器沙箱内执行，控制台通过 postMessage 返回。预览默认阻止外部资源和网络请求，代码不会上传、保存或依赖后端。

常见问题

RunJS 会把代码上传到服务器吗？

不会。HTML、CSS 和 JavaScript 都在当前浏览器的沙箱 iframe 中执行，控制台消息通过本地 postMessage 返回，不依赖后端。

为什么图片或接口请求没有加载？

预览默认限制外部资源和网络请求，以降低示例代码带来的风险。请在本地开发环境中验证需要外部资源的功能。

自动运行和手动运行有什么区别？

手动运行只在点击运行时更新预览；自动运行会在停止编辑约 0.7 秒后执行最新代码。
