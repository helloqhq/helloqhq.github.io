条形码生成器

免费在线生成 Code128、EAN-13、UPC-A 和 Code39 条形码，自动补齐或验证校验位，调整尺寸与文字并下载 PNG 或 SVG。全部在浏览器本地处理。

工具介绍

输入编号即可实时生成条形码，支持 Code128、EAN-13、UPC-A 和 Code39 四种编码。可调整条宽、高度与文字字号，下载 PNG 位图或 SVG 矢量图。

EAN-13 和 UPC-A 支持自动计算末位校验码，也会校验完整编号，避免把无效编号直接输出为图片。

适用场景

  • 为内部库存、设备或文件编号制作标签。
  • 用已有商品编号制作条形码图片。
  • 为页面、文档或印刷排版导出 SVG 条形码。

使用步骤

  1. 选择条形码类型，输入内容或点击示例。
  2. 调整尺寸与是否显示文字，检查预览及校验提示。
  3. 下载 PNG 或 SVG；实际打印后用扫描设备核验。

能力范围与限制

  • 最多 128 个字符；Code128 支持可打印 ASCII，Code39 支持大写字母、数字及部分符号。
  • EAN-13 输入 12 或 13 位数字，UPC-A 输入 11 或 12 位数字。
  • 保持黑条白底及静区；生成图片不等于获得 GS1 商品编号授权。

数据处理说明

条形码在浏览器本地生成，输入不会上传服务器。
