cURL转代码

将 cURL 命令转换为 JavaScript Fetch、Python Requests 或 Node.js Fetch 代码，解析请求方法、请求头、查询参数、请求体和 Basic Auth。浏览器本地处理，不发送请求。

工具介绍

粘贴从浏览器开发者工具、接口文档或终端复制的 cURL 命令，即可生成 JavaScript Fetch、Python Requests 或 Node.js Fetch 请求代码。支持 Bash/POSIX 引号、反斜杠换行、请求头、Cookie、文本请求体、JSON 请求体与 Basic Auth。

工具只解析命令并生成代码，不执行命令，也不会发送任何网络请求。变量替换、命令拼接和文件上传等无法安全转换的写法会明确报错，避免生成与原命令行为不一致的代码。

适用场景

  • 把浏览器“复制为 cURL”的接口请求转为前端调试代码。
  • 将接口文档中的 cURL 示例改写为 Python 脚本。
  • 在 Node.js 中快速复现一次 HTTP 请求。

使用步骤

  1. 粘贴完整的 cURL 命令，或点击示例。
  2. 选择 JavaScript Fetch、Python Requests 或 Node.js Fetch。
  3. 点击转换，检查生成代码后复制或下载。

能力范围与限制

  • 最多 200,000 字符；仅支持 http/https 地址及常用的请求、请求头、数据、Cookie、认证和重定向参数。
  • 不支持读取文件（如 -d @file、-F 表单上传）、Shell 变量、命令替换、管道与代理等参数。
  • 浏览器 Fetch 受 CORS 和受限请求头约束；包含 Token、Cookie 等凭据的代码请勿公开分享。

数据处理说明

cURL 命令在浏览器本地 Worker 中解析，不执行命令、不发送请求，也不上传或保存输入。
