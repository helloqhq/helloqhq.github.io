JavaScript格式化与压缩

纯前端 JavaScript 格式化与压缩工具，支持缩进设置、ES Module 模式、局部变量名压缩、语法错误提示、复制与下载，代码不上传不执行。

工具介绍

将 JavaScript 代码整理为便于阅读的缩进格式，或通过语法解析压缩代码。可选择缩进、脚本模式和局部变量重命名；代码不会上传或执行。

适用场景

  • 阅读压缩脚本、整理文档或代码评审中的 JavaScript 片段。
  • 在保留字符串、正则及模板内容的前提下压缩脚本。

使用步骤

  1. 粘贴 JavaScript，按需设置缩进与压缩模式。
  2. 点击格式化或压缩；处理失败时查看语法诊断，原输入会保留。
  3. 复制结果或下载 .js 文件。单次最多处理 200,000 个字符，可取消。

常见问题

格式化会执行代码吗？

不会。处理在本地 Worker 中解析文本，不调用运行或上传服务。

压缩会改变变量名吗？

默认不重命名变量；勾选后缩短可重命名的局部名称，保留函数名、类名及对象属性名。ES Module 模式允许顶层优化，应仅用于模块代码。许可注释会保留。

支持 TypeScript 或 JSX 吗？

首版面向 JavaScript，不保证 TypeScript 或 JSX 处理。解析通过也不代表代码在实际环境中能够正确运行。
