Php编辑器

PHP 在线代码编辑器，支持语法高亮、代码折叠、查找替换、一键与快捷键格式化，以及 PHP 文件导入下载。代码仅在浏览器本地处理，无需安装软件。

工具介绍

在浏览器里新建或导入 PHP 文件，使用语法高亮、行号、代码折叠和查找替换完成编辑，再下载到本地。

纯 PHP 文件可一键格式化，或在编辑器内按 Shift + Alt + F（macOS 为 Shift + Option + F）。所有编辑与格式化均在浏览器本地完成，代码不会上传，也不会执行。

适用场景

  • 临时修改 PHP 文件、配置片段或文档示例，无需启动 IDE。
  • 整理纯 PHP 代码的缩进、空格和换行，并通过撤销恢复格式化前的内容。
  • 编辑 PHP 与 HTML 混合文件并导出；混合文件暂不支持一键格式化。

使用步骤

  1. 新建 PHP 文件、粘贴代码或导入本地 .php 文件。
  2. 修改内容，按需使用查找替换、代码折叠和格式化。格式化失败时原文会保留。
  3. 调整文件名，复制代码或下载 UTF-8 编码的 .php 文件。允许偏好存储后，可在当前浏览器恢复草稿。

常见问题

PHP 代码会上传或执行吗？

不会。文件编辑和格式化均在当前浏览器内完成，不调用后端执行或格式化接口。

格式化支持哪些文件？

支持带 PHP 标签的纯 PHP 文件，默认 4 空格缩进、目标行宽 100 列。PHP 与 HTML 混合文件可以编辑，但不进行格式化。

如何恢复格式化前的代码？

在编辑器内使用撤销快捷键 Ctrl + Z，macOS 为 Command + Z。格式化作为一次操作进入撤销历史。
