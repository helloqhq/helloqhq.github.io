HTML转Markdown

将 HTML 源码或 UTF-8 文件转换为 Markdown，保留标题、列表、链接、引用、代码块和常规表格，支持高亮查看、复制及下载，不执行脚本、不加载远程资源。

工具介绍

粘贴 HTML 源码或导入 UTF-8 HTML 文件，将文章和富文本片段整理为 Markdown。输入输出均支持语法高亮，结果可复制或下载为 .md 文件。

适用场景

  • 将 HTML 文章或富文本导出片段整理为 Markdown 文档。
  • 提取标题、列表、引用、代码块和常规表格用于知识库。

使用步骤

  1. 粘贴 HTML 或导入 UTF-8 文件。最多 200,000 字符、10,000 节点和 80 层嵌套，文件上限 1 MiB。
  2. 点击转为 Markdown，检查右侧只读结果和转换提示。
  3. 复制或下载 .md 文件；修改输入后旧结果会清除。

常见问题

能还原原网页的样式吗？

转换保留支持的内容结构，不保留 CSS 布局、样式或脚本交互。合并单元格、不规则和嵌套表格会转为可读文本并提示。

会执行 HTML 或请求图片吗？

不会。源码在惰性文档中处理，不插入当前页面，不执行脚本或加载外部资源。图片只转换为引用文本。

没有表头的表格如何转换？

使用空 Markdown 表头，并保留所有原始数据行，不会将首行数据改成标题。结果上限为 2,000,000 字符。
